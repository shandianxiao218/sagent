# A 股主线交易策略

使用本 skill 时，所有分析和输出默认使用中文。

## 判断模型

- 默认明确使用 **GLM5.1** 做主线、形态、关键点和持仓判断。
- 配置允许时，可以切换到 **GPT-5.5**。
- 输出中应记录本次判断使用的模型名称。

## 交易范围

只关注 A 股，策略目标是主线板块中的强势个股。

## 买入形态

只考虑：

1. 处在上升趋势或主升浪中。
2. 已经发生回调或整理。
3. 正在突破短期回调趋势。
4. 所属板块是当前市场主线或强主线候选。

## 风控规则

- 单次开仓使用总资金的 10%。
- 每周最多新开仓 2 次。
- 止损：
  - 跌破买点前关键低点；或
  - 单笔亏损达到 5%。
- 止盈：
  - 盈亏比达到 2.5–3 时止盈一半；
  - 剩余仓位在趋势破坏时全部退出。

## 输出要求

LLM 给出建议时必须包含：

- 建议动作：买入 / 观察 / 放弃 / 持有 / 减仓 / 清仓。
- 判断理由。
- 所属板块是否主线。
- 买点前关键低点。
- 无效条件和风险点。
- 使用的判断模型。

## 禁止事项

- 不自动下单。
- 不把分析结果表述为确定收益。
- 不省略风险提示。
- 不构成投资建议。
