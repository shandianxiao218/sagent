# A 股主线交易策略

使用本 skill 时，所有分析和输出默认使用中文。

## 判断模型

- 默认明确使用 **GLM5.1** 做主线、形态、关键点和持仓判断。
- 配置允许时，可以切换到 **GPT-5.5**。
- 输出中应记录本次判断使用的模型名称。

## 交易范围

只关注 A 股，策略目标是主线板块中的强势个股。

## 核心概念

- **主线**：当前资金、涨幅、涨停扩散同时占优的申万二级行业。强主线满足连续 5 日成交额前 10、30 日内至少 3 次涨幅前 10、30 日内至少 3 次出现 3 只以上涨停；弱主线满足成交额和涨幅条件但扩散不足，需要 LLM 二次判断。
- **上升趋势 / 主升浪**：价格处于长期均线（默认 250 日均线）之上，60 日内出现明显上涨波段，且上涨幅度足以证明资金强度。
- **回调**：从阶段高点回撤前一波涨幅的 15%–50%，未破坏更大级别上升结构。
- **整理**：回调后波动收敛、成交量相对下降，等待方向选择。
- **短期回调趋势突破**：近几日价格重新回升并突破短期下降趋势或整理上沿，形成可定义买点。
- **买点前关键低点**：利弗摩尔体系中的同级别结构转折低点，不是简单前 N 日最低价。
- **趋势破坏**：更大级别上升趋势结构被破坏，通常表现为跌破同级别上升趋势最后一个关键低点。

## 买入形态

只考虑：

1. 处在上升趋势或主升浪中。
2. 已经发生回调或整理。
3. 正在突破短期回调趋势。
4. 所属板块是当前市场主线或强主线候选。

## 风控规则

- 单次开仓使用总资金的 10%。
- 每周最多新开仓 2 次。
- 止损：
  - 跌破买点前关键低点；或
  - 单笔亏损达到 5%。
- 止盈：
  - 盈亏比达到 2.5–3 时止盈一半；
  - 剩余仓位在趋势破坏时全部退出。

## 输出要求

LLM 给出建议时必须包含：

- 建议动作：买入 / 观察 / 放弃 / 持有 / 减仓 / 清仓。
- 判断理由。
- 所属板块是否主线。
- 买点前关键低点。
- 无效条件和风险点。
- 使用的判断模型。

## 禁止事项

- 不自动下单。
- 不把分析结果表述为确定收益。
- 不省略风险提示。
- 不构成投资建议。
