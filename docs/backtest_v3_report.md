## 8. 关键结论

### 8.1 积极信号
1. **策略整体盈利**：纯量化 23 个信号平均 +9.32%，胜率 69.6%
2. **趋势期表现优秀**：2025-12、2026-01、2026-04 三个月胜率 100%
3. **LLM 过滤有增量价值**：虽然规则引擎模拟效果差（精确率 40%），但真实 LLM 盲判精确率达 83%（方案 A 结果），说明 LLM 层确实能提升候选池质量

### 8.2 需要改进
1. **止损率偏高**：30.4% 的信号亏损超 5%，主要集中在 2026-02~03 回调期
2. **规则引擎模拟 LLM 效果差**：精确率 40%、召回率 18%，与真实 LLM（83% 精确率）差距巨大
3. **行业数据缺失**：无法验证主线逻辑
4. **ST 股票混入**：ST 京蓝（000711）出现在信号中且被"放弃"，但仍计入统计

### 8.3 下一步建议
1. **修复行业查询接口**，重跑完整 L6 主线验证
2. **集成 backtest_engine.py 到回测脚本**，用逐日止损/止盈替代持有 20 天
3. **用真实 LLM API** 替代规则引擎模拟，获取更精确的精确率
4. **扩大采样到 1500 只**，增加信号数量，使统计更有意义
5. **过滤 ST 股票**（应在信号检测前排除）
6. **对 2026-02~03 的 7 个亏损信号做专项分析**，找出共同特征
