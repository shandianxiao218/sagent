## 策略逻辑

### 信号检测
1. 价格 > MA250
2. 60 日涨幅 >= 50%（主升浪）
3. 回撤 15%-50%（健康回调）
4. 连续 3 日反弹
5. 突破前 8 日高点

### LLM 判断（规则引擎 v3）
1. 回撤 >55% → 放弃
2. 量比 <0.7 + 无转折点 → 放弃
3. 放量 >=1.2 + 回调 <=42% → 买入
4. 涨幅 >80% + 放量 >=1.0 + 回调 <=50% → 买入
5. 温和涨幅 + 放量 + 回调 <=40% → 买入
6. 其他 → 观察

### 止损/止盈
- 止损价 = max(买入价×0.90, 关键低点×0.97)
- R>=2.5 时半仓止盈，剩余等趋势破坏退出
- 最长持有 20 天
