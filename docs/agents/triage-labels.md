# Triage 标签

工程 skills 使用五个标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| skill 中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待提问者或需求方补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，AFK agent 可以直接处理 |
| `ready-for-human` | `ready-for-human` | 需要人类参与决策、确认或实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色，例如“打上 AFK-ready 标签”，使用上表中的实际标签字符串。

如果以后更换标签命名，只修改本文件右侧映射即可。
